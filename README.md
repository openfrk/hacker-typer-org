# ⚡ hacker-typer-org

An interactive, high-tech Cyberpunk Terminal simulator built with pure HTML5, CSS3, and JavaScript. It features dynamic log streaming, customizable neon aesthetics, synthesized mechanical sound effects, and a built-in global live chat panel.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![GitHub Pages](https://img.shields.io/badge/deployment-GitHub%20Pages-brightgreen)

## 🌟 Key Features

- ⌨️ **Interactive Stream Logging:** Generates real-time security logs, thread intercepts, and quantum alignments instantly with every keystroke or click.
- 💬 **F6 Global Live Chat:** Press **`F6`** (or click the `[F6] CHAT` HUD button) to open a slide-out global chat drawer.
- 👤 **Nickname Authentication:** Mandatory nickname setup saved locally before entering the chat room.
- 🚫 **100% Human-Only Chat:** Strictly zero bots or fake chat generators. Real user interaction only.
- 🔊 **Synthesized Sound Effects:** Integrated Web Audio API mechanical "click" sound effects on keypress without needing external sound assets.
- 🎨 **Multi-Theme Support:** Switch seamlessly between Cyberpunk color palettes (*Night City, Neon Protocol, Synthwave 84, Matrix Deep, Tokyo Overdrive*).
- 📊 **Real-time System HUD:** Live simulated metrics for CPU, RAM, and Network throughput.
- 🚀 **Zero Dependencies & Serverless:** 100% client-side code, instantly deployable to **GitHub Pages** or usable as a stream overlay source (OBS/Streamlabs).

## 🎮 How to Use

1. Press any key or click anywhere on the screen to trigger system log streams.
2. Toggle **AUTO: ON** from the top bar for automatic log generation.
3. Press **`F6`** to open the chat panel, set your **Nickname**, and start chatting with other users!
4. Click **THEME** to switch between 5 different neon color modes.
